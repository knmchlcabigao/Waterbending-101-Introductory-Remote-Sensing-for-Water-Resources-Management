# GEE-Waterbending-101

This repository contains the codes and materials used in the Environmental Hydrology Laboratory’s training workshop series, **“Waterbending 101: Introductory Remote Sensing for Water Resources Management.”**

The workshop introduces the use of satellite-derived datasets for hydrologic analyses and watershed monitoring. This repository serves as a learning guide to access, visualize, and produce meaninful geospatial data analyses using Google Earth Engine (GEE).
